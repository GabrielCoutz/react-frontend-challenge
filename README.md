# CineDash

Dashboard de curadoria e descoberta de filmes, construído para o desafio técnico de Desenvolvedor React Pleno.

A proposta simula uma ferramenta interna usada por curadores de cinema para descobrir, filtrar e gerenciar uma lista de filmes via [TMDB API](https://developer.themoviedb.org).
